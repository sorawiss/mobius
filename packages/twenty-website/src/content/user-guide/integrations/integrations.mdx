## เกี่ยวกับ

Mobius สามารถใช้งานร่วมกับ Zapier เพื่อทำงานอัตโนมัติได้

## Zapier

เชื่อมต่อ Mobius กับแอปกว่า 3000+ รายการผ่าน <ArticleLink href="https://zapier.com">Zapier</ArticleLink> แล้วทำงานให้เป็นอัตโนมัติ ทำตามขั้นตอนต่อไปนี้เพื่อเชื่อมต่อ Mobius เข้ากับ Zapier:

1. ไปที่ Zapier และลงชื่อเข้าใช้
2. คลิก `+ Create Zap` ที่แถบด้านซ้าย
3. เลือกแอปที่จะใช้เป็น Trigger (เหตุการณ์ที่เริ่มการทำงานอัตโนมัติ)
4. เลือก Mobius เป็น Action (เหตุการณ์ที่ให้ Zapier ทำเมื่อถูก Trigger) <ArticleLink href="https://zapier.com/how-it-works">ดูเพิ่มเติมเกี่ยวกับ Trigger และ Action ใน Zapier</ArticleLink>
5. เมื่อเลือกบัญชี Mobius ที่ต้องการใช้กับการทำงานอัตโนมัติแล้ว ให้อนุญาตให้ Zapier เข้าถึงโดยเพิ่ม API Key ดูวิธีสร้าง API Key ได้ที่ [/user-guide/section/functions/api-webhooks](/user-guide/section/functions/api-webhooks)
6. ใส่ API Key และกด 'Yes, Continue to Mobius'

คุณสามารถดำเนินการสร้างอัตโนมัติต่อได้เลย!
